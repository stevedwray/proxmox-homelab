# .continue/prompts.md
# Custom Prompts for Proxmox Homelab Development

## Infrastructure as Code Prompts

### Terraform Module Generation
```
Generate a Terraform module for [COMPONENT] with the following requirements:
- Follow HashiCorp's module standards
- Include comprehensive variable validation
- Add proper output values
- Include examples and documentation
- Consider security best practices
- Support both test and production environments
```

### Ansible Role Development
```
Create an Ansible role for [TASK] that includes:
- Proper role directory structure
- Idempotent tasks with appropriate handlers
- Comprehensive variable definitions with defaults
- Proper error handling and validation
- Tags for selective execution
- Molecule tests for validation
```

## Security-Focused Prompts

### Security Hardening
```
Review and enhance the security of this [TERRAFORM/ANSIBLE] code:
- Identify potential security vulnerabilities
- Suggest hardening improvements
- Ensure secrets are properly managed
- Validate network security configurations
- Check for principle of least privilege
- Recommend monitoring and logging improvements
```

### Compliance Check
```
Validate this infrastructure code against security best practices:
- Check for CIS benchmarks compliance
- Verify encryption at rest and in transit
- Ensure proper access controls
- Validate backup and disaster recovery
- Review logging and monitoring setup
```

## Operational Prompts

### Backup Strategy
```
Help me design a comprehensive backup strategy for:
- ZFS datasets and snapshots
- LXC container configurations
- Critical application data
- Automation scripts and configurations
- Recovery procedures and testing
```

### Monitoring Setup
```
Create monitoring and alerting configuration for:
- Proxmox host health
- Container resource usage
- Storage capacity and performance
- Network connectivity
- Backup job status
- Security events
```

## Troubleshooting Prompts

### Infrastructure Debugging
```
Help me troubleshoot this infrastructure issue:
- Analyze error messages and logs
- Identify root cause and contributing factors
- Provide step-by-step resolution steps
- Suggest prevention measures
- Recommend monitoring improvements
```

### Performance Optimization
```
Analyze and optimize this configuration for performance:
- Resource allocation and utilization
- Network configuration and throughput
- Storage performance and efficiency
- Container optimization
- Automation script performance
```

## Development Workflow Prompts

### Code Review
```
Perform a comprehensive code review focusing on:
- Code quality and maintainability
- Infrastructure best practices
- Security considerations
- Documentation completeness
- Testing coverage
- Error handling
```

### Documentation Generation
```
Generate comprehensive documentation for:
- Architecture overview and diagrams
- Installation and setup procedures
- Configuration options and examples
- Troubleshooting guides
- API references
- Change management procedures
```
