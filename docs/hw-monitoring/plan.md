## Design (decided; do not re-litigate in execution)

- One new Prometheus job, `node_exporter_hw`, in VictoriaMetrics' `scrape.yml`.
  Scheme https + the existing `prometheus` basic auth, same as `node_exporter`.
  It is separate from `node_exporter` so its sensor relabeling cannot touch
  the LXC fleet, and so the dashboard can filter on one job.
- Targets and friendly sensor names live in ONE data file,
  `terraform/lxc/stacks/monitoring-stack/hwmon-hosts.yml`, read by
  `deploy-monitoring-stack.yml`. No hostnames hardcoded elsewhere.
- Friendly names are applied at scrape time: every `node_hwmon_*` series gets a
  `sensor_name` label. Default is `<chip>/<sensor>`; entries in
  `hwmon_sensor_names` override it per `(stack, chip, sensor)`.
- Hosts get the agent via the existing `node_exporter` role (TLS from step-ca,
  basic auth). The role gains one variable, `node_exporter_listen_address`,
  because T-Pot's docker-proxy owns :9100 (T-Pot uses :9101).
- The Grafana dashboard `hardware-health` is generated by
  `scripts/gen_hardware_dashboard.py`; the JSON is committed, the script is the
  source of truth.
- The Argon Pi 4 fans have no tachometer (I2C-driven by `argononed`), so they
  get temperature and undervoltage only. Do not invent fan RPM for them.
- T-Pot: see the Revision section above (container on :8084, plain HTTP).
- Rendering uses `| to_json` inside `content: |`, never `{% for %}` blocks or
  `to_nice_yaml`: both were tested and break YAML indentation.

## Phase A: Super I/O driver identification (operator-approved, prod hosts)

This is not a step block: it changes production hosts and needs a per-host
Preflight Summary and "Proceed". Do pve-tiny first (simpler chip), then pve.
In-tree `nct6775.ko` and `it87.ko` already exist under
`/lib/modules/$(uname -r)/kernel/drivers/hwmon/` on both hosts (checked
2026-10-17), so no DKMS build is needed to try.

**A1. pve-tiny (MSI B450 GAMING PLUS MAX, expected NCT6795D class chip).**
Read-only first: `dmesg | grep -i -E 'nct|it87|acpi.*conflict'`, then
`modprobe nct6775` and re-read dmesg and `sensors`. Success = a `nct67*`
hwmon chip with `fan*_input` and `in*_input` files. If dmesg shows
`ACPI: resource ... conflicts`, stop: the fix is the kernel parameter
`acpi_enforce_resources=lax`, which needs a reboot of a production node and its
own approval. To persist after success:
`echo nct6775 > /etc/modules-load.d/hwmon.conf`.

**A2. pve (Gigabyte B550 GAMING X V2, expected ITE IT8688E).**
`modprobe it87`, then read dmesg. Mainline `it87.ko` here describes itself as
"IT8705F/IT871xF/IT872xF", so IT8688E may be reported as an unknown chip
(`it87: Found unknown chip`) or not probed at all. Outcomes:
(a) chip recognised: persist via `/etc/modules-load.d/hwmon.conf`, done;
(b) not recognised: STOP and present options. Option 1: out-of-tree DKMS
`it87` (needs `proxmox-headers`, `dkms`, build tools on a prod host, rebuilt
on every kernel update). Option 2: leave pve temperature-only. Option 3: boot
param `it87.force_id=0x8628`-style forcing; riskier, only if the operator asks.
Never build DKMS without explicit approval.
`sensors-detect` is NOT used: it writes to I/O ports; the modprobe test above
is the least invasive identification.

**Gate to proceed to Phase C for a host:** `sensors` shows fan and voltage
inputs for that host, or the operator records "temperature only" for it.

Script for this step (copy verbatim):

```python
#!/usr/bin/env python3
"""Write Raspberry Pi 5 PMIC rail readings for node_exporter's textfile collector.

Reads `vcgencmd pmic_read_adc` (lines like `  3V3_SYS_A current(1)=0.121A`
and `  3V3_SYS_V volt(9)=3.3045V`) and writes rpi_pmic_current_amps /
rpi_pmic_volts, one series per rail, atomically.
"""
import os
import re
import subprocess
import sys

OUT = sys.argv[1] if len(sys.argv) > 1 else "/var/lib/node_exporter/textfile_collector/rpi_pmic.prom"
VCGENCMD = "/usr/bin/vcgencmd"
LINE = re.compile(r"^\s*(\S+)_([AV])\s+(?:current|volt)\(\d+\)=([0-9.eE+-]+)[AV]\s*$")

raw = subprocess.run([VCGENCMD, "pmic_read_adc"], capture_output=True, text=True, check=True).stdout
cur, volt = [], []
for line in raw.splitlines():
    m = LINE.match(line)
    if not m:
        continue
    rail, kind, value = m.groups()
    (cur if kind == "A" else volt).append(f'{{rail="{rail}"}} {float(value)}')

lines = ["# TYPE rpi_pmic_current_amps gauge"]
lines += [f"rpi_pmic_current_amps{s}" for s in cur]
lines += ["# TYPE rpi_pmic_volts gauge"]
lines += [f"rpi_pmic_volts{s}" for s in volt]

tmp = OUT + ".tmp"
with open(tmp, "w") as fh:
    fh.write("\n".join(lines) + "\n")
os.replace(tmp, OUT)
```

Script for this step (copy verbatim):

```python
#!/usr/bin/env python3
"""Generate terraform/lxc/stacks/monitoring-stack/dashboards/hardware-health.json.

Run from the repo root:  python3 scripts/gen_hardware_dashboard.py
The JSON is committed; this script is the source of truth for its layout.
"""
import json
import pathlib

OUT = pathlib.Path("terraform/lxc/stacks/monitoring-stack/dashboards/hardware-health.json")
DS = {"type": "prometheus", "uid": "VictoriaMetrics"}
SEL = '{job=~"node_exporter_hw.*",stack=~"$host"}'

_id = 0


def _next_id():
    global _id
    _id += 1
    return _id


def row(title, y):
    return {"collapsed": False, "gridPos": {"h": 1, "w": 24, "x": 0, "y": y},
            "id": _next_id(), "panels": [], "title": title, "type": "row"}


def ts(title, expr, legend, unit, x, y, w=12, h=8, vmin=None, vmax=None):
    defaults = {"color": {"mode": "palette-classic"},
                "custom": {"lineWidth": 1, "fillOpacity": 10}, "unit": unit}
    if vmin is not None:
        defaults["min"] = vmin
    if vmax is not None:
        defaults["max"] = vmax
    return {"datasource": DS, "fieldConfig": {"defaults": defaults, "overrides": []},
            "gridPos": {"h": h, "w": w, "x": x, "y": y}, "id": _next_id(),
            "options": {"legend": {"calcs": ["mean", "max"], "displayMode": "table",
                                   "placement": "bottom"},
                        "tooltip": {"mode": "multi"}},
            "targets": [{"expr": expr, "legendFormat": legend, "refId": "A"}],
            "title": title, "type": "timeseries"}


def stat(title, expr, legend, unit, x, y, w=6, h=4, steps=None):
    steps = steps or [{"color": "green", "value": None}]
    return {"datasource": DS,
            "fieldConfig": {"defaults": {"unit": unit, "color": {"mode": "thresholds"},
                                         "thresholds": {"mode": "absolute", "steps": steps}},
                            "overrides": []},
            "gridPos": {"h": h, "w": w, "x": x, "y": y}, "id": _next_id(),
            "options": {"colorMode": "background", "graphMode": "none",
                        "reduceOptions": {"calcs": ["lastNotNull"], "fields": "", "values": False}},
            "targets": [{"expr": expr, "legendFormat": legend, "refId": "A"}],
            "title": title, "type": "stat"}


TEMP_STEPS = [{"color": "green", "value": None}, {"color": "orange", "value": 75},
              {"color": "red", "value": 90}]
LEG = "{{stack}} {{sensor_name}}"

panels = [
    row("Overview", 0),
    stat("Hottest sensor", f"max by (stack) (node_hwmon_temp_celsius{SEL})",
         "{{stack}}", "celsius", 0, 1, w=8, steps=TEMP_STEPS),
    stat("Slowest running fan (non-zero)",
         f"min by (stack) (node_hwmon_fan_rpm{SEL} > 0)", "{{stack}}", "rpm", 8, 1, w=8),
    stat("Pi undervoltage alarm (1 = active)",
         f"max by (stack) (node_hwmon_in_lcrit_alarm_volts{SEL})", "{{stack}}", "none", 16, 1, w=8,
         steps=[{"color": "green", "value": None}, {"color": "red", "value": 1}]),
    row("Temperatures", 5),
    ts("Temperatures", f"node_hwmon_temp_celsius{SEL}", LEG, "celsius", 0, 6, w=24, h=10),
    row("Fans", 16),
    ts("Fan speed", f"node_hwmon_fan_rpm{SEL}", LEG, "rpm", 0, 17, vmin=0),
    ts("Fan PWM duty", f"node_hwmon_pwm{SEL} / 255", LEG, "percentunit", 12, 17,
       vmin=0, vmax=1),
    row("Voltages and power", 25),
    # `scale` label (default 1, set per divider-fed rail) is read as a number
  # by MetricsQL label_value(); VERIFY this live in Phase C before step 07.
  ts("Voltages", f"node_hwmon_in_volts{SEL} * label_value(node_hwmon_in_volts{SEL}, \"scale\")",
     LEG, "volt", 0, 26),
    ts("Power", f'{{__name__=~"node_hwmon_power(_average)?_watt",job=~"node_exporter_hw.*",stack=~"$host"}}', LEG, "watt", 12, 26, vmin=0),
    row("Raspberry Pi 5 power rails (PMIC)", 34),
    ts("PMIC rail voltages",
       f'rpi_pmic_volts{{job=~"node_exporter_hw.*",stack=~"$host"}} > 0',
       "{{stack}} {{rail}}", "volt", 0, 35),
    ts("PMIC rail currents",
       f'rpi_pmic_current_amps{{job=~"node_exporter_hw.*",stack=~"$host"}}',
       "{{stack}} {{rail}}", "amp", 12, 35, vmin=0),
]

dash = {
    "annotations": {"list": []},
    "description": "Hardware sensors (temperatures, fans, voltages) from node_exporter's hwmon collector, with friendly sensor names applied at scrape time",
    "editable": True, "fiscalYearStartMonth": 0, "graphTooltip": 1, "id": None,
    "links": [], "panels": panels, "refresh": "30s", "schemaVersion": 38,
    "tags": ["lab", "hardware"],
    "templating": {"list": [{
        "name": "host", "label": "Host", "type": "query", "datasource": DS,
        "definition": 'label_values(node_hwmon_temp_celsius{job=~"node_exporter_hw.*"}, stack)',
        "query": {"query": 'label_values(node_hwmon_temp_celsius{job=~"node_exporter_hw.*"}, stack)',
                  "refId": "A"},
        "refresh": 2, "sort": 1, "multi": True, "includeAll": True,
        "allValue": ".+", "current": {}, "hide": 0}]},
    "time": {"from": "now-6h", "to": "now"}, "timepicker": {}, "timezone": "browser",
    "title": "Hardware Health", "uid": "hardware-health", "version": 1,
}

OUT.write_text(json.dumps(dash, indent=2) + "\n")
print(f"wrote {OUT}")
```
